# hey, i'm sanju 👋

designer, founder. i run [ThisUX](https://thisux.com), a design-led product studio. we make things that work.

for years i wore many hats. now i'm doing my own thing: building products, shipping open source, and getting builders in one room through [unitedby.ai](https://unitedby.ai).

## what i'm building

- **[DroidClaw](https://droidclaw.ai)**: turn old android phones into ai agents. give it a goal in plain english, and it reads the screen, taps and types via adb, and loops until the job is done. [open source](https://github.com/unitedbyai/droidclaw)
- **[DunSocial](https://dunsocial.com)**: ai social media scheduler that learns your voice, then writes and posts for you across X, LinkedIn, Threads, Bluesky, Reddit and more. it also has an mcp server, so you can post from claude, cursor or codex.
- **[ThisUX Voice](https://github.com/thisuxhq/voice)**: a typescript sdk for real-time voice agents. `createVoice({ stt, llm, tts })` and you're talking.
- **[SticAI](https://sticai.com)**: rewrite anything, anywhere. one shortcut to fix grammar, change tone or translate, right where you're typing.
- **[DunTasks](https://duntasks.com)**: organize, collaborate, ship better.
- **[Fli.so](https://github.com/thisuxhq/fli.so)**: an open-source url shortener built with sveltekit and pocketbase.
- **[sveltednd](https://github.com/thisuxhq/sveltednd)**: a lightweight drag and drop library for svelte 5.
- **[U/AI](https://unitedby.ai)**: where ai builders meet and ship. in person, no networking fluff.

always building and tinkering.
